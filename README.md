# 微信 AI 桌面回复助手

一个运行在 Windows 上的微信回复助手。默认以置顶的桌面小宠物显示消息和候选回复，不需要打开网页；你点击某条候选后，程序才会把它发送到微信。

**首次使用没有预设联系人。** 请自行填写微信昵称或备注名，并确认接收对象后再开始使用。

## 当前功能

- **桌面候选回复**：监听已配置联系人的文本消息，参考最近对话生成候选回复；点击候选即发送，也可以选择“先忽略”。默认使用人工确认模式。
- **指定联系人**：在小宠物中填写并保存微信昵称或备注名；编辑联系人时会暂停监听，保存后重新连接。
- **智谱 GLM 接入**：在本地配置 API Key、接口地址和模型名称。
- **聊天风格参考**：点击“分析聊天记录”读取目标会话，建立本地风格画像和相似对话示例；可通过“参考聊天风格”开关控制使用。
- **表情包**：支持按情绪分类的本地素材库，以及从微信聊天窗口截图导入静态表情；发送前可勾选“只发文字，不带表情包”。
- **可选网页管理**：保留 AI 答复、系统配置，以及原有好友、分组、消息和知识库等管理页面。具体微信操作能力受 `wxauto4` 免费版限制。

## 运行环境

- Windows 桌面环境，微信 PC 客户端已登录，主窗口可以正常显示和操作。
- Python 3.10 或更高版本，安装时包含 Tcl/Tk；项目的 Python 版本文件指定为 3.10。
- [uv](https://docs.astral.sh/uv/)：用于按锁文件安装后端依赖。
- 能访问所配置的模型接口，并拥有对应模型的调用权限。
- **只有网页模式需要 Node.js 18+ 和 npm**；默认桌面模式不依赖前端服务。

微信控制通过 `wxauto4` 免费版的 Windows UI Automation 完成。不同微信客户端版本的兼容性以实际连接结果为准；好友详情全量同步、修改备注等部分 Plus 能力不可用。

## 首次安装

以下命令在 PowerShell 中执行。

### 1. 获取项目并安装依赖

```powershell
git clone https://github.com/luoxuxusdhubp/AI_application.git
cd AI_application
uv sync --project backend --locked
```

依赖会安装到 `backend/.venv`，启动器优先使用这个环境。后端依赖以 `backend/pyproject.toml` 和 `backend/uv.lock` 为准。

### 2. 配置智谱 API

首次配置时复制模板；已有 `.env.local` 时，直接编辑原文件即可。

```powershell
Copy-Item .env.local.example .env.local
```

在项目根目录的 `.env.local` 中填写自己的配置：

```dotenv
ZHIPU_API_KEY=your_api_key_here
ZHIPU_API_BASE=https://open.bigmodel.cn/api/paas/v4
ZHIPU_MODEL=glm-4-flash
```

将 `your_api_key_here` 替换为真实密钥，模型名称改为你的智谱账号实际可用的模型。这里的值仅是示例，不提供可直接使用的密钥。配置修改后建议重启助手。

### 3. 启动桌面助手

在项目根目录双击 `微信AI助手.exe` 或 `启动微信助手.bat`，也可以执行：

```powershell
.\backend\.venv\Scripts\python.exe launcher.py
```

`微信AI助手.exe` 是启动器，仍需要完整项目文件、Python 环境和已安装的依赖。

启动器会启动或复用本地后端，然后打开桌面小宠物。关闭小宠物窗口，或在启动窗口按 `Ctrl+C`，会结束本次启动的进程。

### 4. 设置联系人并使用

1. 在小宠物的“目标联系人”中填写微信昵称或备注名，点击“保存”。默认值为空，不附带任何个人联系人。
2. 等待助手连接微信并开始监听。
3. 对方发来文本消息时，小宠物会显示消息和候选回复，通常提供 3 条候选。
4. **点击候选会直接发送到微信**；不想发送时点击“先忽略”。
5. 如需调整回复口吻，可以在网页“系统配置”中编辑系统提示词。

程序通过操作微信窗口读取或发送内容。监听、历史分析和表情导入可能切换窗口或占用输入焦点；操作期间请留意界面状态。

## 聊天风格与表情包

### 参考自己的聊天风格

保存目标联系人后，点击“分析聊天记录”。程序会读取该会话中的历史消息，在本地建立风格画像和相似情境示例。

“参考聊天风格”开启时，生成回复可使用这些信息；关闭后不再注入对应的历史风格信息。历史分析会操作微信窗口，过程中请不要同时手动操作该窗口。

### 添加或导入表情包

可将 PNG、JPG、GIF 素材放入情绪目录，例如：

```text
backend/stickers/
├── happy/       # 开心
├── love/        # 表达喜欢
├── comfort/     # 安慰
└── thanks/      # 感谢
```

在小宠物中开启“表情包”后，程序会为合适的候选选择素材。勾选“只发文字，不带表情包”可跳过当前回复的表情发送。

“导入表情包”会从目标聊天窗口截图，裁剪你自己发过的表情，保存到 `backend/stickers/inbox/`。请先检查导入结果，再将图片移入对应情绪文件夹；`inbox` 中的图片不会参与发送。

截图导入得到的是静态图片，动图只能截取其中一帧；裁剪和相似图片去重可能需要手工调整。也可以通过 `STICKER_DIR` 环境变量指定其他素材目录。

## 可选：网页管理模式

安装前端依赖后，通过带参数的批处理文件进入网页管理：

```powershell
npm ci
.\启动微信助手.bat --web
```

| 地址 | 用途 |
| --- | --- |
| `http://127.0.0.1:3000` | 网页管理入口 |
| `http://127.0.0.1:8000` | 本地后端服务 |
| `http://127.0.0.1:8000/docs` | API 文档 |

默认桌面模式只启动后端和小宠物，未启动网页前端时，3000 端口不会提供页面。

## 数据与密钥

- 真实 API 密钥保存在本地 `.env.local` 中，仓库仅提供 `.env.local.example` 模板。
- 联系人设置、聊天语料、回复草稿等数据保存在本地 SQLite 数据库 `backend/wechat_friends.db` 中，首次启动会创建所需表。
- `.gitignore` 已排除真实环境配置、数据库、日志、缓存、虚拟环境和个人表情素材。
- 启用模型回复后，相关消息、上下文，以及启用的历史风格摘要和示例，可能发送给所配置的模型服务。

## 常见问题

**启动器一闪而过或提示缺少模块**：先运行 `uv sync --project backend --locked`，再从 PowerShell 执行 `launcher.py` 查看错误。不要将启动器单独移出项目目录。

**连接不到微信**：确认微信 PC 客户端已登录且主窗口可操作，并检查当前客户端与所安装 `wxauto4` 的兼容性。

**没有生成候选回复**：先确认目标联系人已经保存、名字与微信显示一致、监听状态正常，再检查 `.env.local` 和模型调用权限。运行日志位于 `backend/logs/`。

**网页打不开**：默认启动的是桌面模式。需要网页时，先安装前端依赖，再运行 `启动微信助手.bat --web`。
